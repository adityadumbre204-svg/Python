📘 Console Record-Management Application
📌 Project Title
Mini Project – Console Record-Management Application (Python Programming & Relational Database)

📖 Project Description
This project is a console-based record-management application developed in Python.
It allows users to add, view, search, update, and delete records using a menu-driven interface.
The application integrates core Python concepts such as data types, conditional statements, loops, functions, exception handling, and file I/O into a single working program.

✨ Features
Menu-driven console interface

Add new records with ID, Name, and Course

View all records in tabular format

Search records by ID or Name

Update existing records

Delete records

File I/O using JSON for persistent storage

Exception handling for invalid inputs and file errors

🛠️ Technologies / Concepts Used
Python 3.x

Data Types & Variables

Conditional Statements & Loops

Functions

Exception Handling

File I/O (JSON)

Menu-driven Application Design
